# SiteCraft

Лендинг студии SiteCraft — создание сайтов для малого и среднего бизнеса.

## Структура

- `index.html` — главная (и единственная) страница
- `css/style.css` — стили
- `js/main.js` — скрипты (без внешних зависимостей)
- `img/` — изображения (пока пусто)

## Запуск локально

Откройте `index.html` в браузере или запустите простой сервер:

```bash
python -m http.server 8000
```

## Публикация

Сайт статический, подходит для GitHub Pages: включите Pages в настройках репозитория, источник — ветка `main`, папка `/ (root)`.

## Безопасность

Проект не использует внешних библиотек, CDN и сторонних запросов — поверхность атаки минимальна.
